GACT abstracts forward propagation as loss and context functions, compressing context tensors to reduce memory. It introduces an unbiased stochastic compressor Q(·) and linearizes the gradient function g(·; θ) using a first-order Taylor expansion (ˆg(Q(h); h,θ)). This linearized gradient (ˆg) is shown to be an unbiased stochastic gradient, with its approximation error bounded by the compression error. The convergence theory (Theorem 1) relies on assumptions about loss function continuity, boundedness, and bounded linearization error (A3) and variance of the linearized gradient (A4). This relies on assumptions that compressed results are element-wise uncorrelated (B1) and compression error variance can be factorized (B2), which are met by a stochastic rounding quantizer. Tensor sensitivity cl(h,θ) is numerically computed by leveraging compressor idempotence (B3) and empirical variance from two gradient evaluations (Algorithm 1). GACT uses low-level PyTorch hooks, efficient CUDA kernels for sensitivity inference and compression, and a per-group quantizer (similar to ActNN but with adaptive tensor-level quantization).
