# Paper Outline
EcoTTA consists of a memory-efficient architecture and a self-distilled regularization. The architecture uses a pre-trained model where the original networks are frozen during test time to avoid storing large intermediate activations for backpropagation. Lightweight meta networks, each comprising one batch normalization and one convolution block (Conv-BN-ReLU), are attached to K partitioned parts of the original network's encoder. These meta networks are pre-trained on the source dataset for a small number of epochs before deployment. During test-time adaptation, only these lightweight meta networks are updated using an unsupervised loss, specifically entropy minimization, applied to samples whose entropy is below a predefined threshold. The self-distilled regularization is introduced as an L1 loss, Rk(θk) = ||˜xk − xk||1, which penalizes deviations between the output of the k-th meta network group (˜xk) and the corresponding output of the frozen original network (xk). This regularization runs in parallel with the adaptation loss, maintaining source knowledge and stability without extra memory.
