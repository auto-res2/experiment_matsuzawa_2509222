# Paper Outline
GACT's methodology is founded on a general theoretical framework for ACT. It first analyzes a linearized version of ACT's stochastic gradient (SG), proving that it is an unbiased estimator, and that the linearization error is bounded by the compression error. The variance of this linearized gradient has a simple structure, separating sampling variance from compression variance. An adaptive algorithm is then employed to determine the compression ratio for each tensor. This algorithm numerically estimates the sensitivity (cl) of each context tensor by evaluating the empirical variance of the gradient, keeping random seeds fixed for all compressors except the target tensor. Based on these sensitivities and a total bit budget, an integer programming problem is approximately solved using an O(Llog2L) greedy algorithm to select the optimal per-tensor compression strategy. The implementation is a lightweight PyTorch library that uses low-level PyTorch hooks to capture context tensors, supports arbitrary operators, filters out non-activation tensors, avoids duplication via tensor footprints, and integrates parallel swapping/prefetching and gradient checkpointing.
