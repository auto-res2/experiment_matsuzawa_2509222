# Paper Outline
The core methodology involves formulating the optimization of sampling variance as an adversary bandit problem. Instead of directly computing intractable optimal sampling distributions, the approach maintains nonparametric estimates of the sampler, updating them towards optimal variance after partial knowledge about sampled neighbors is acquired. The reward for an action (choosing a set of neighbors) is defined as the negative derivative of the effective sampling variance. Two bandit algorithms are proposed: GNN-BS, based on multi-armed bandit (MAB), which samples one neighbor repeatedly 'k' times and updates the sampler using EXP3; and GNN-BS.M, based on MAB with multiple plays, which uses an efficient k-combination sampler (DepRound) to select a combinatorial set of 'k' neighbors at once and updates using EXP3.M. For attentive GNNs, adjusted feedback attention values are introduced to approximate true attention values from sampled unnormalized attentions.
