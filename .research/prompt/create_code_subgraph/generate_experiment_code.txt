EXPERIMENT 2 – Uncertainty-Aware Abstention & Theoretical Bound Check
--------------------------------------------------------------------------------
Goal: Show that the variance head σ̂ supplies a reliable risk estimate, allowing compute savings with a provable accuracy upper-bound.

2. Procedure
   a) Run SWIFTADAPT with τ_skip ∈ {0,0.25,0.5,0.75,1.0} (percentage of blocks skipped based on σ̂).
   b) Log for every sample i: (σ̂_max,i, block-skip mask, top-1 correctness).
   c) Compute empirical ΔAcc(τ_skip)=Acc(0)−Acc(τ_skip).
   d) Plot ΔAcc against theoretical bound ε(τ_skip) given in paper.
   e) Measure GPU FLOPs & latency versus τ_skip.

   • All empirical ΔAcc curves lie strictly below ε(τ_skip).

   • Hyper-net gϕ: Dual-Path hyper-network (CNN branch + 2-layer 128-d Transformer branch) producing rank-1 factors.
   • Baselines: Source (no TTA), TENT, CoTTA, OSHA, FLASHADAPT (official code / default hyper-parameters^1).

D. Pre-processing
   ImageNet-C: 256-pixel short-side resize → center-crop 224 → RGB mean/std normalisation.
   CIFAR-C: convert to Tensor → mean/std normalisation using CIFAR statistics.
   NOTE: No test-time data augmentation to isolate TTA effect.

E. Data Splitting
   Because evaluation is fully online, the whole corruption stream serves as test.  Meta-training of SWIFTADAPT (identical to FLASHADAPT meta-training) is performed offline on ImageNet-train with synthetic shifts (not part of this benchmark).  For robustness we replay the 100-k image ImageNet-C stream with 3 random corruption orderings (3 seeds).

F. Execution Protocol
   1. Pin batch-size = 64 (ImageNet-C) / 256 (CIFAR-C) to fit comfortably in 80-GB VRAM.
   2. Activate TF32 + cuDNN 8.9 for all runs.
   3. Record start/end wall time with time.time() and query NVML power every 200 ms.
   4. Compute C(g) = (elapsed_time_SWIFTADAPT ÷ elapsed_time_Source).
   5. All methods run on a single A100; CPU pinned to 16 physical cores; I/O threads pre-fetch next batch to RAM.

G. Hyper-parameters
   • LAS decay α ∈ {0.05, 0.1, 0.2}.  Default 0.1.
   • Temperature of variance head β = 0.05.
   • Rank-k injection: k = 1 (ours) vs k = 2 (ablation).

      • Energy / image (J)

      • ECE (Expected Calibration Error)^2

A. Purpose
   Validate that σ̂ from the variance head provides statistically valid risk signals and that empirical accuracy loss stays below the analytic bound ε(τ_skip).

B. Dataset
   • 50 k ImageNet-C images (severity 3) with 50 k clean ImageNet-val images randomly interleaved (to vary shift intensity).

C. Model
   • ResNet-50 + SWIFTADAPT (LAS decay 0.1, meta-trained as in Exp-1).

D. Procedure
   1. For each τ_skip ∈ {0.00, 0.25, 0.50, 0.75, 1.00} do:
      a) For every incoming sample obtain σ̂_max = max_b σ̂_b.
      b) If σ̂_max > τ_skip   → do NOT inject Δ for that block (skip)  ↔ saves compute.
   2. Log correctness, σ̂_max, and blocks skipped.
   3. Post-run: compute

        ε(τ)    = Φ⁻¹(1−τ)·σ         (closed-form from paper, σ pre-computed on meta-train).
   4. Plot ΔAcc vs ε.  95 % CI via bootstrap over frames.
   5. Measure FLOPs & latency with fvcore after masking blocks.

E. Metrics
   • Empirical accuracy loss vs bound.
   • % blocks skipped, latency reduction, energy reduction.

F. Success criteria
   • ∀τ: ΔAcc(τ) < ε(τ) (strict).
   • τ=0.5 should skip ≈30 % blocks → ≥10 % latency drop with <0.3 pp accuracy loss.

G. Hyper-parameter sweep
   • Evaluate different LAS decay α to show bound generalises.
