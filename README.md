# HASHPIPE-GAT Sub-Logarithmic Attention for Billion-Scale Graphs
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Graph attention networks deliver state-of-the-art accuracy on many graph learning tasks but remain prohibitively expensive on real-world power-law graphs whose hub nodes own up to one million neighbours. Even the most recent efficient kernels still spend Θ(log d) work per high-degree node at every epoch and repeatedly recompute almost identical attention patterns. We introduce HASHPIPE-GAT, a fully pipelined accelerator that lowers the expected per-node cost to O(|C| + log log d + T) through four ideas: (i) an epoch-wise progressive top-K cache that reuses the neighbours with the largest past attention weights; (ii) a three-stage 16/32/64-bit SimHash cascade that early-rejects edges using warp-level bit counting; (iii) a signed CountSketch estimator that replaces exact query–key dot-products with an (ε, δ)-relative-error approximation; and (iv) layer-shared memoisation combined with 2:4 weight sparsity and activation compression. Implemented as a single fused CUDA kernel in PyTorch, HASHPIPE-GAT attains 1.5–4× speed-ups over HiPPO-GAT while matching or exceeding its accuracy on Reddit, OGB-Arxiv, OGB-Products and OGB-Papers100M, and is the first method that trains a 12-layer full-batch model on Papers100M within 30 GB of GPU memory. A micro-study confirms that the empirical sketch error stays beneath the theoretical bound and that 96 % of true top-32 edges survive the stochastic filter, while a hub-stress test up to degree 10^6 shows a 30× cost reduction after five epochs. These findings establish temporal reuse and probabilistic sketching as practical tools for billion-scale graph attention.
